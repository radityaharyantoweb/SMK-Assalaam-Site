# SMK PPMI Assalaam School Profile Website

A school profile website project for **SMK PPMI Assalaam**, developed as part of my learning journey in web development.

## About the Project

This project aims to create a website that presents information about SMK PPMI Assalaam, including school information, departments, and contact details.

The project also serves as a practical application of front-end web development concepts learned during my studies in Teknik Jaringan Komputer dan Telekomunikasi (TJKT).

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- Sass/SCSS

## Website Pages

- **Home:** Main page of the school website.
- **About:** Information about the school.
- **Departments:** Information about the school's departments.
- **Contact:** Contact information.

## Project Structure

The project includes HTML pages, styling files, assets, and supporting resources used to build the website.

- `index.html` – Home page
- `about.html` – About page
- `jurusan.html` – Departments page
- `contact.html` – Contact page
- `scss/` – Sass/SCSS source files
- `css/` – CSS stylesheets
- `assets/` – Images and other supporting resources

## Learning Objectives

- Practice building multi-page websites using HTML and CSS.
- Apply Bootstrap for front-end layout and styling.
- Learn to organize and compile Sass/SCSS stylesheets.
- Improve website structure and front-end development skills.

## Project Status

Developed as a learning project. Features and content may be updated as the project progresses.
